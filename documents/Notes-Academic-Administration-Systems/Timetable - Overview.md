# Timetable - Overview

> [!tip] Source
> Extracted from: https://www.cityu.edu.hk/arro/creg/schd_main.htm
> Fetched: 2026-10-30

## Question

How does the **class schedule / timetable** work at CityUHK?

## Answer

## University Class Hours

Classes at CityUHK are normally held during the following hours:

| Day | Time |
|-----|------|
| **Monday to Friday** | 9:00 am – 6:50 pm |
| **Monday to Friday (evening)** | 7:00 pm – 10:50 pm |

## Master Class Schedule

- The **Master Class Schedule** for the academic year is released in AIMS
- It lists all course sections offered, including their **CRN**, section code, campus, and whether the course is **web-enabled**

## Personal Class Schedule

- Your **Personal Class Schedule** is released in AIMS for each semester/term
- It shows the specific course sections you are enrolled in, with their class times and venues

## Key Dates

- **Master Class Schedule** for the academic year: released in July
- **Personal Class Schedule** for Semester A: released in July
- **Personal Class Schedule** for Semester B: released in November
- **Personal Class Schedule** for Summer Term: released in April

## Course Section Information

Each course section in the schedule includes:

- **CRN** (Course Reference Number)
- **Section code** (e.g., lecture, tutorial, laboratory)
- **Campus** (e.g., main campus, Kowloon Tong)
- **Class time and venue**
- **Web-enabled** flag (whether it can be added/dropped online)

## Exam Timetable

- The **examination schedule** is released in AIMS for each semester/term
- Semester A exam schedule: released in November
- Semester B exam schedule: released in March
- Summer Term exam schedule: released in July

## How to Access

- Log in to **AIMS** using your **CityUHK EID**
- View your class schedule under \[Course Registration > Personal Class Schedule\]
