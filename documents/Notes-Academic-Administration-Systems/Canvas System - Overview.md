# Canvas System - Overview

## Question

What is the **Canvas** learning management system at CityUHK?

## Answer

## What is Canvas?

**Canvas** is the current unified learning management system (LMS) at CityUHK, provided by **Instructure, Inc.** It enables teachers and students to interact for learning and teaching purposes.

## Key Features

- **Hosting**: CityUHK Canvas is hosted by **Amazon Web Services (AWS)** in Singapore under a software-as-a-service (SaaS) model
- **Updates**: Users are using the latest version of Canvas with rolling updates every **two weeks**
- **Course sites**: Course sites are created based on the **Master Class Schedule** before every semester to facilitate learning and teaching activities online
- **Access**: Teachers and students can find the link to Canvas on CityUHK homepage under "Quick Links"

## How to Access

- URL: https://canvas.cityu.edu.hk/
- Log in with your **CityUHK EID** and password
- After logging in:
  - **Teachers** will see the courses they are teaching
  - **Students** will see what courses they have registered for
