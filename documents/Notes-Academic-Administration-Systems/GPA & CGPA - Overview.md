# GPA & CGPA - Overview

> [!tip] Source
> Extracted from: https://www.cityu.edu.hk/arro/asmt/cgrd_main.htm
> Fetched: 2026-10-30

## Question

How does the **GPA / CGPA** system work at CityUHK?

## Answer

## Grade Point Scale

CityUHK uses a **4.3-point scale** for grading:

| Grade | Grade Points |
|-------|--------------|
| **A+** | 4.3 |
| **A** | 4.0 |
| **A-** | 3.7 |
| **B+** | 3.3 |
| **B** | 3.0 |
| **B-** | 2.7 |
| **C+** | 2.3 |
| **C** | 2.0 |
| **C-** | 1.7 |
| **D** | 1.0 |
| **F** | 0.0 |

## SGPA vs CGPA

- **SGPA** (Semester Grade Point Average) — the GPA for a single semester
- **CGPA** (Cumulative Grade Point Average) — the cumulative GPA across all semesters of study

## How GPA is Calculated

- GPA is calculated by dividing the **total grade points earned** by the **total credit units attempted**
- Grade points are calculated by multiplying the **grade point value** by the **credit units** of the course
- GPA is **truncated to 2 decimal places** (not rounded)

## Course Repeat

- If a course is repeated, the **latest grade** is used in the GPA calculation
- The previous grade remains on the transcript but is not counted in the GPA

## Dean's List

- Students with a **GPA of 3.7 or above** in a semester, with **12 or more credit units** and **no failures**, may be placed on the **Dean's List**

## Award Classifications

The award classification for a degree is based on the CGPA:

| Classification | CGPA |
|----------------|------|
| **First Class Honours** | 3.50 or above |
| **Upper Second Class Honours** | 3.00 – 3.49 |
| **Lower Second Class Honours** | 2.50 – 2.99 |
| **Third Class Honours** | 2.00 – 2.49 |
| **Pass** | 1.70 – 1.99 |

## Academic Standing

Academic standing is determined by the CGPA:

| Standing | CGPA |
|----------|------|
| **Good Standing** | 2.00 or above |
| **Academic Warning** | Below 2.00 |
| **Academic Probation** | Below 1.70 (or as specified) |
| **Academic Suspension** | Below the probation threshold |

## How to Access

- View your grades and GPA in **AIMS** under \[Course Registration > Course Grades\]
