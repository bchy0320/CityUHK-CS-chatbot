# Software & Licenses - FAQ

> [!tip] Source
> Extracted from: https://www.cityu.edu.hk/its/services-facilities/list-of-services-facilities/c/campus-wide-software-licenses
> Fetched: 2026-10-30

## Question

What are the common questions about **software and licenses** at CityUHK?

## Answer

## Q1: How do I access campus-wide software?

Software is available in staff and student PCs through the **'Work Desk' icon** on the Windows Desktop.

## Q2: Can I install Microsoft Office on my own computer?

Yes. Regular full-time and part-time students are entitled to **Microsoft 365 Apps for Students**, under which they can install and use the latest versions of Microsoft Office via the **Microsoft EES** on up to a maximum of **five machines** (PCs or Macs) owned and used by the students during their studies. Students can also run **Office Mobile** for Android or iPhone on up to **5 mobile devices**.

## Q3: Can I use Adobe Creative Cloud?

Yes. The University has signed an **Enterprise Term License Agreement (ETLA)** with Adobe which allows staff to use Adobe Creative Cloud (CC) subscriptions at lower annual cost. Licensed users can install and use the latest versions on multiple devices with their user accounts.

## Q4: Can I use MATLAB?

Yes. The University has subscribed to the MathWorks **Total Academic Headcount (TAH)** license, providing access to MATLAB, Simulink and all eligible MathWorks products (80+ tools). The TAH license allows installation on university-owned or personally-owned computers. **MATLAB Online** is also available via a web browser.

## Q5: Can I use SPSS?

Yes. The University has joined the **SPSS Site Licensing Programme** for the Joint Universities Computer Centre Limited (JUCC). The site license fee is substantially discounted but shared amongst participating JUCC institutions.

## Q6: Can I use Foxit PDF Editor?

Yes. The University has acquired licenses for **Foxit PDF Editor (Named License)** for both Windows & Mac. Licensed users can install and use the latest versions on up to **two devices** with their user accounts.

## Q7: Can I use VMware software?

Yes. The University has signed an **Enterprise License Agreement (ELA)** with VMware, entitling CityUHK to unlimited rights to deploy the latest version of the corresponding VMware software.

## Q8: Can I use Sophos Endpoint Protection?

Yes. The University has acquired licenses of **Sophos Endpoint Protection** for Windows & Mac, which can be installed on University-owned computers and users' personal computers.

## Q9: What if the software I need is not available?

For teaching studios, if required software is not on the list, instructors may request to have the software added via **CSC Work Request**.
