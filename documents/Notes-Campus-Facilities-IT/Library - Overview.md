## Question

What is the **Run Run Shaw Library** at CityUHK and what services does it provide?

## Answer

## What is the Run Run Shaw Library?

The **Run Run Shaw Library** is the university library of CityUHK. It provides a wide range of library and research support services to students and staff, including borrowing, interlibrary loan, course reserve, reference and research support.

## Key Services

| Service | Description |
|---------|-------------|
| **Circulation** | Borrowing and returning of library materials |
| **Interlibrary Loan** | Request materials not held by the Library from other libraries |
| **Course Reserve** | Access to course-specific reserved materials |
| **Virtual Instruction and Reference Help Desk** | Online reference and research assistance |
| **IT Help Desk** | IT support within the Library |
| **Research Support and Scholarly Communication** | Support for CityUHK Scholars, Open Access, research impact, author IDs, and research data management |
