## Sample Study Schedules

Each student should plan his/her own study schedule to earn credit units for the MSc in Computer Science award. The plan can be formulated with the assistance and advice from academic staff. Below are some sample study schedules for illustration purpose.

Refer to **[Taught Postgraduate Catalogue](http://www.cityu.edu.hk/pg/current/catalogue/catalogue_TP.htm?page=TP/TP_course_CS.htm)** for more information of individual courses.

#### SAMPLE Full-time Study Plan (taking Project course with No Stream)

| Semester A | CS5222 Computer Networks and Internets | CS5351 Software Engineering | CS5481 Data Engineering | CS5187 Vision and Image | CS5489 Machine Learning: Algorithms and Applications | 
| Semester B | CS6520 Project | CS5182 Computer Graphics | CS5483 Data Warehousing and Data Mining | CS6290 Privacy-enhancing Technologies |  | 
| Summer Term | CS6520 Project (continued) |  |  |  |  | 


#### SAMPLE Full-time Study Plan (Information Security Stream)

| Semester A | CS5222 Computer Networks and Internets | CS5351 Software Engineering | CS5481 Data Engineering | CS5285 Introduction to Cybersecurity | CS5294 Information Security Technology Management | 
| Semester B | CS5182 Computer Graphics | CS5491 Artificial Intelligence | CS5483 Data Warehousing and Data Mining | CS6290 Privacy-enhancing Technologies | CS6537 Guided Study in Information Security | 


#### SAMPLE Part-time Study Plan (Artificial Intelligence Stream)

| Year 1 |  |  |  | 
|---|---|---|---|
| Semester A | CS5222 Computer Networks and Internets | CS5481 Data Engineering | CS5187 Vision and Image | 
| Semester B | CS5182 Computer Graphics | CS5487 Machine Learning: Principles and Practice |  | 
| Year 2 |  |  |  | 
| Semester A | CS5351 Software Engineering | CS5486 Intelligent Systems | CS5489 Machine Learning: Algorithms and Applications | 
| Semester B | CS5491 Artificial Intelligence | CS5182 Computer Graphics |  | 

The courses offered in each semester may very depending on student demand, staff availability, and other circumstances.
