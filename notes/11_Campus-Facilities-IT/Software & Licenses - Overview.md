# Software & Licenses - Overview

> [!tip] Short answer
> CityUHK purchases campus-wide software licenses for teaching, learning, and research, available on staff and student PCs via the **'Work Desk' icon** on the Windows Desktop. Key licenses include **Adobe Creative Cloud** (ETLA), **Foxit PDF Editor** (named license, up to 2 devices), **Microsoft 365 Apps for Students** (EES, up to 5 machines), **VMware** (ELA), **MathWorks MATLAB/Simulink** (TAH, with MATLAB Online), **SPSS** (JUCC site license), and **Sophos Endpoint Protection**. Some software may require a separate subscription at a substantial discount under the enterprise agreement.

## Question

What **software licenses and subscriptions** are available to CityUHK students?

## Answer

## Campus-wide Software Licenses

The University purchased software licenses and subscriptions for teaching, learning and research purposes, which are available in staff and student PCs through the **'Work Desk' icon** on the Windows Desktop. Some software may require separate subscription at substantial discount under the enterprise agreement.

## Available Software Licenses

| Software | License Type | Details |
|----------|--------------|---------|
| **Adobe** | Enterprise Term License Agreement (ETLA) | Adobe Creative Cloud (CC) subscriptions at lower annual cost; install on multiple devices with user accounts |
| **Foxit** | Named License | Foxit PDF Editor for Windows & Mac; install on up to two devices |
| **Microsoft** | Microsoft Enrollment for Education Solutions (EES) | Microsoft 365 Apps for Students; install latest Microsoft Office on up to five machines (PCs or Macs); Office Mobile on up to 5 mobile devices |
| **VMware** | Enterprise License Agreement (ELA) | Unlimited rights to deploy the latest VMware software |
| **MathWorks** | Total Academic Headcount (TAH) | MATLAB, Simulink and 80+ MathWorks products; MATLAB Online available via web browser |
| **SPSS** | SPSS Site Licensing Programme (JUCC) | Site license fee substantially discounted but shared amongst participating JUCC institutions |
| **Sophos Endpoint Protection** | University license | For Windows & Mac; install on University-owned and personal computers |

## How to Access

- Software is available in staff and student PCs through the **'Work Desk' icon** on the Windows Desktop
- Some software may require separate subscription at substantial discount under the enterprise agreement
